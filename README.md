# 🏪 Retail Store Performance Prediction

Predicting retail store performance using Decision Tree and K-Nearest Neighbors (KNN).

---

## 📌 Project Overview

This project analyses retail store operational data to classify store performance.

The workflow includes:

- Data Cleaning
- Exploratory Data Analysis
- Feature Scaling
- Model Training
- Model Comparison
- Performance Evaluation

---

## 📂 Dataset

Retail Store Dataset

Target:

- Good Performance
- Bad Performance

---

## 🛠️ Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

---

## 🔧 Data Preprocessing

- Missing value inspection
- Negative staff value correction using median imputation
- Label Encoding
- Feature Scaling

---

## 🤖 Models

### Decision Tree

Accuracy: **60.7%**

### K-Nearest Neighbors

Accuracy: **60.7%**

---

## 📊 Evaluation

Both Decision Tree and KNN achieved similar performance on the test dataset.

| Model | Accuracy |
|--------|---------:|
| Decision Tree | 60.7% |
| KNN | 60.7% |

---

## 💡 Key Findings

- Data preprocessing successfully handled invalid staff values.
- Both classification models produced comparable predictive performance.
- Additional feature engineering and hyperparameter tuning could further improve accuracy.
